# Quality checklist — MathEdu Maroc

Before relying on a generated worksheet in class:

- [ ] Generate 10 worksheets for each lesson and inspect arithmetic answers.
- [ ] Check decimal comma formatting and negative-number signs.
- [ ] Check fraction simplification, zero numerators, and equal rational numbers.
- [ ] Check the explanatory steps against classroom methods and Moroccan curriculum.
- [ ] Print with corrections shown and hidden; verify pagination.
- [ ] Check mobile layout and keyboard navigation.
- [ ] Test offline loading in a modern browser.
- [ ] Confirm GitHub Pages deployment succeeds in Actions and the published URL loads.
- [ ] Add automated math tests before expanding to additional lessons.
